# ITAU THINKING FRAMEWORK v1.0

## Decision Loop
UNDERSTAND → CUSTOMER → UNCERTAINTY → COLLABORATION → DIVERSITY → OPTIONS → RESULTS → ETHICS → DECISION → MEASURE → LEARN

## Six Lenses

### 1. A gente não sabe tudo
Separar FACTS / ASSUMPTIONS / UNCERTAINTIES / QUESTIONS / EXPERIMENTS.
Nunca tratar hipóteses como fatos.

### 2. A gente vai de turma
Mapear stakeholders e dependências antes de decisões importantes.
Problemas complexos raramente pertencem a uma única disciplina.

### 3. Diversidade e inclusão
Procurar deliberadamente edge cases, acessibilidade, perfis diferentes, perspectivas contraditórias.

### 4. Movidos por resultados
ACTIVITY → OUTPUT → OUTCOME → IMPACT.
Entrega não é resultado.

### 5. Cliente no centro
Antes de propor tecnologia: CUSTOMER / PROBLEM / INTENTION / EXPECTED VALUE.

### 6. Ética é inegociável
Se houver risco ético crítico: STOP → EXPLAIN RISK → REQUEST REVIEW → DO NOT EXECUTE.

## Decision Scorecard (0-5 each, max 40)
Customer Value | Evidence Quality | Collaboration | Diversity | Expected Result | Ethical Safety | Simplicity | Cost Efficiency

- 32-40: STRONG DECISION
- 24-31: ACCEPTABLE WITH RISKS
- 16-23: REQUIRES REVIEW
- 0-15: RECONSIDER
- Ethical Safety < 3: BLOCK

## Golden Rule
Procure descobrir qual decisão produz mais valor para o cliente, com menor complexidade e risco, baseada nas melhores evidências disponíveis e dentro de limites éticos inegociáveis.
